# 帖磊·设计作品合集

双击 `index.html` 打开改进版。`原版.html` 是线上页面的本地原样副本，可用于对照。两者共用本文件夹内的作品素材；浏览本地作品无需联网或启动服务器，跳转外部品牌官网仍需联网。

## 文件结构

- `01-品牌设计` 至 `05-其他设计`：135 个作品原文件，包含图片、视频、PDF 和 30 份 XLSX 表格。
- `assets`：网页缩略图、视频封面、40 张 PDF 逐页预览图和 30 个表格的 HTML 预览页。
- `style.css`、`app.js`、`viewer.js`：改进版样式和交互；`assets/sheet-viewer.js`：表格预览的缩放与拖拽；`original-style.css`、`original-app.js`：原版样式和交互。
- `qa`：桌面与手机视图截图，以及交互检查结果。

## 本地改进

1. 两处品牌网页长图在原有尺寸内支持滚轮或触屏上下浏览，边缘渐隐提示剩余内容；点击仍可查看完整长图。
2. 调整档案、精选区和关于区的标题断行与手机字号。
3. 手机导航保留“精选”“全部作品”直达入口，将“关于”“联系”收进菜单。
4. 手机档案筛选按需展开，第一组作品更早进入视野；品牌网页用可读的封面比例展示。
5. 包装设计补充“印刷展开图”说明和展示边框，避免将生产图误读为成品效果图。
6. 首屏轻微入场，导航、作品入口和按钮提供短暂反馈；手机菜单与作品预览平滑开合。键盘操作即时响应，开启系统“减少动态效果”时停用位移动效。
7. 点击图片、PDF、视频或表格，会在统一预览框中打开。滚轮以鼠标位置为中心缩放，按住拖拽移动，点击“适应”恢复初始大小；PDF 可逐页切换，顶部可打开原文件。表格预览中按住 Alt 拖拽可选取文字。

`mirror-assets.mjs` 可重新核对并下载缺失的线上素材；`qa-local.mjs` 可重新生成本地浏览器截图。素材镜像清单见 `asset-manifest.json`。

`.qa-edge-profile` 和 `.qa-edge-mobile` 是首次截图检查留下的临时浏览器配置，各约 6.5 MB；它们不参与网页运行。

## 部署

运行 `node build.mjs` 会把公开网页所需文件整理到 `dist`。Cloudflare Pages 使用 `dist` 作为输出目录。
